# Wasn't Me

Wasn't Me is a small add-on for World of Warcraft that will automatically create and / or update a macro for Misdirection or Tricks of the Trade in the personal macro section. The macro will only be created, if there is a macro slot available.

The created macro is surprisingly called WasntMe :-)

# Known limitations

The macro in its current version works well within 5 player groups, raids only have a best-effort support.

The add-on is bound to the WoW Lua API limitations and can only update the macro out of combat.
